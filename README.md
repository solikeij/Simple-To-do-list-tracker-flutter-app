# Daylist — Hive model and adapter version

A dark-mode Flutter to-do app for ITP107 Finals Laboratory 2, retaining the
requested palette, seven extra fields, editing, swipe deletion, and filters.

## Setup

Open this folder in VS Code or Android Studio and run:

```sh
flutter pub get
dart run build_runner build --delete-conflicting-outputs
flutter analyze
flutter test
flutter run
```

Use Flutter with Dart 3.6.1 or later. The bundled task.g.dart is a supplied
adapter implementation following the reference format. The generation command
recreates it from the annotated model; it was not generated by a Flutter SDK
in this editing environment. Flutter was unavailable here, so dependency
resolution, adapter generation, compilation, tests, and device UI remain unverified.

## Dependencies

Runtime: hive ^2.2.3, hive_flutter ^1.1.0.
Development: hive_generator ^2.0.1, build_runner 2.4.13, plus the original
Flutter test/lint dependencies. build_runner is pinned for the starter's Dart
3.6-era toolchain. No unrelated provider or database package is required.

## Existing data

openTaskBox converts the previous map records to Task objects in the same
 taskBox, preserving their keys and all fields. It validates all records before
writing, leaves existing Task records untouched, and never clears data during
migration. Do not change typeId 1 or reuse field IDs 0–9 for different fields.
Do not run the older map-only app against the converted box.

The seven optional text fields are description, category, priority, time,
location, reminder note, and tags. Time and reminder notes do not schedule
notifications. Data is stored on the device and is not cloud-synced.
